# Separate a search failure from a late intervention

14 October 2026. Both exact historical prefixes qualify, but the fixed exact/24
method loses its beam before a complete continuation. No attempt or time cap is
exhausted. Simply raising those caps would not change that deterministic stopping
point. Exact grouping makes no removals; width pruning removes 822 candidates,
without establishing that any removed candidate could complete.

The next milestone is **an independently qualified control-search comparison at
the same first-fire state**. Preserve every input, original deadline and geometry
constraint. First qualify a released kinodynamic control-planning adapter against
retained known-feasible controls, including narrow turns and stop/restart behavior.
Include a small prospectively frozen constructive braking/steering control set as
a diagnostic. Then compare on the unchanged source case under explicit propagation,
geometry-query, wall-time and memory caps. The alternative method must not consume
the successful reset-time controls as a witness to this changed initial state.

The falsifying result is a complete independently replayed continuation from this
same history: it would rule out source-model unavoidability and expose a limitation
of the tested search/proposals/selection. A second finite miss still would not
prove uncontrollability. An impossibility claim needs a separately justified bound
covering the allowed action set; neither finite beam trace supplies that bound.
Do not infer a causal pruning failure from the number of removed candidates.

This comparison should precede moving the trigger earlier. An earlier intervention
might work, but would answer a different question and could conceal a method
limitation at the current decision time. If a complete source continuation is
admitted, preregister native execution of the preserved history and chosen suffix.
Then measure a fixed decision window and total online cost before an information
advantage test against a competent responsive baseline.

Required next resources begin with local CPU and public released source. Freeze
adapter identities, control semantics, fixture acceptance, equal-cost accounting,
missingness and stopping before source outcomes. The [primary-source review](RESEARCH.md)
and [earlier released-method audit](../iter162_source_grouping_qualification/RESEARCH_UPDATE.md)
provide candidates, not a benchmark result. No new native/GPU run or learned model
expansion is needed to qualify that adapter. Iter135 remains deferred; all current
owned work is closed and no human ceremony is pending.
