# Equal-work continuation comparison on the retained frontier

Exploratory paired comparison after the closed Iter179 audit. Retain all 19 late
endpoint records and probe each of their 16 distinct numeric states once per arm,
using the earliest representative. No new retained-root outcome has been acquired
for this comparison. The roots, previous outcomes and witness controls are exposed
development evidence; this is not holdout validation. Integrated qualification
remains Iter178's 3/4 and source comparison stays closed.

The primary claim is that the fixed stepwise search gains at least one verified
checkpoint continuation with no loss against the retained program generator under
equal per-run ceilings. Both arms start at the exact retained state and absolute
clock, and seek any admissible state at checkpoint frame 16. Retain all physical,
foreground, background, route-distance, checkpoint and premature-completion rules.
This changes the objective from original sampled-target matching to checkpoint
feasibility; it is not a replay of the original directed requests.

Each root/arm receives at most 128 attempted transitions and three seconds checked
before propagation. There are 32 runs and at most 4,096 attempts. Check clocks
before each transition as the existing implementations do; an in-progress operation
and finalization may finish after the deadline. Record actual search time. No hard
real-time guarantee is asserted. Each run starts its clock before target arithmetic
and method construction. Materialization and independent replay are outside its
search clock, inside the 900-second stage envelope. No unused work or time transfers
between roots or arms. Alternate program-first and beam-first by representative
index, yielding eight roots in each order. No retries or post-outcome retuning.

The common deterministic target rule is defined in MATHEMATICS.md. It uses only
state, clock and route, with no rollout, root ID, previous outcome or witness input.
It supplies the retained generator's seed and its original partial-path ranking.
The beam retains its existing route guidance and exact state grouping. Thus the
comparison concerns two complete local search procedures, including their guidance
and order; it does not isolate pure control expressivity or one ranking coefficient.
Target proximity is not an additional witness criterion for either arm.

Program arm: directly reuse the Iter177 generator and corrected Iter178 evaluator,
including the analytic initial seed, all three phase patterns, Halton sequence,
byte-keyed cache, complete-horizon reservation and propagation after a rejected
prefix. Charge every actual propagation and background query. A wrapper stops at
the first fully valid program through frame 16. It returns that entire witness,
even if the evaluator's sampled-target ranking preferred an earlier prefix. On a
miss retain the evaluator's original best partial path. No program-family rewrite,
optimizer or constant-only surrogate is allowed. The original 4,096-proposal guard
remains; hitting it is invalid, not an unobserved zero.

Beam arm: reuse the Iter179 stepwise probe with width two and the new 128 cap.
Its 15 physical primitives and three route-feedback proposals are deduplicated in
their original order. Preserve speed-stratified retention, exact grouping, route
ordering and furthest-valid-path return on a miss. Width two is the largest fixed
integer whose worst-case four-step expansion count fits 128 when there are at most
18 successors: at most 126 attempts. This arithmetic does not predict success.
The two progress-excluded roots from Iter179 are still searched; no bound prunes
or skips either arm. The 1,024-cap audit is contextual evidence and is not rerun.

Materialize complete background masks for every queried state in both arms, all
retained prefix paths and every returned path. Independently scalar-check every
materialized mask, count and decision; no new unselected background label remains
unchecked. Exact mask disagreement is invalid even if the coarse decision agrees.
Preserve absent queries when a higher-priority physical/progress rejection preempts
them. Independently check all attempted motion, original program values and cache
accounting, beam proposals/retention, targets, clocks, paths and stopping. Keep
numeric-join ambiguity; do not claim native tree ancestry.

For each pair report both witnesses, gain, loss, both bounded misses or unresolved
censoring. A time-censored run is unknown, not a failed continuation. A verified
loss contradicts the no-loss claim even if another pair is censored. Otherwise,
censoring makes the claim inconclusive; complete observation with a gain and no
loss supports it; no difference is null. Invalid acquisition/admission is never
converted into a null. Report all counts and actual work without confidence
intervals treating these related roots as independent cases.

Constructed controls cover four-step budget feasibility, deadlines/reservations,
changing control programs, cache hits, charged invalid suffixes, target geometry,
full scalar decisions, corrupted records, missing pairs and an adverse case where
the narrow beam loses a valid program witness. Freeze source before one acquisition;
commit raw before independent admission. Stages each have 900 seconds, 1 GiB RSS,
256 MiB raw output and 2 GiB free disk; supervisors allow 910 seconds and reap all
jobs. Verify the selected runtime before and after. Integrated planner budgets,
all four cases and the source-comparison gate remain unchanged.

No native invocation, integrated schedule, driving episode, source recovery query,
provider use or spending. Useful intervention from actual decision histories,
measured sensing/computation/actuation delay and a strong responsive comparator
remain the mission endpoint, not an inferred consequence of this diagnostic.
