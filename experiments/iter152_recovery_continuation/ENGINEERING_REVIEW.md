# Engineering review, 11 October 2026

The immediate high-value experiment is an available-action test. The selected nominal collision
is already observed; comparing unchanged monitor and fixed pulses can distinguish recoverability
from a better warning score. Fourteen remaining runs preserve the earlier disclosed scientific
choices. Repeating the nominal pair or tuning a detector now would not close this question.

The last two integration failures were bookkeeping faults outside the driving worker. Iter152
therefore checks the composition that failed: captured archive, exact Git bytes, scientific
replay and committed admission. Historical evidence stays immutable. Fault tests challenge the
receipt chain and historical-comparator binding; the original scientific implementations remain
unchanged. This is a targeted repair, not proof of industrial readiness.
