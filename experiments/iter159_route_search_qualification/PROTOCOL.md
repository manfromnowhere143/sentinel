# Iter159: constructive route-search qualification

Freeze this protocol, literal CASES, PLAN, source inventory and checks before any
factorial search. Commit all raw before independent admission. One acquisition;
no retries or changes after evidence. Four public development fixtures are bend
left/right and chicane left/right. Mirrors are paired controls, not independent
population samples. The chicane witness starts at 4 m/s and brakes to 2 m/s;
its existence does not prove that every feasible solution must brake.

Each route is interpolated from a manually specified primitive command sequence.
Synthetic 121-center patches flank that path at 2.8 m and one small foreground
box lies 4 m from its midpoint. The exact binary32 center population is retained.
Witnesses are verified before search; the planner API receives only scene geometry,
route, model contract and query access. It receives no fixture ID, witness state
sequence or witness commands. Knowledge of the constructed route is privileged
development evidence; it is not independent perception or road-boundary data.

The 2 by 2 factorial is endpoint/route guidance crossed with rank/speed-group
pruning. Order is fixed in PLAN and mirrored cases retained. Each arm uses the
Iter158 15 acceleration/rate primitives plus its three nominal tracking proposals,
same first-occurrence duplicate removal and hard constraint sequence. All vehicle
limits, 0.25 s update, foreground sweep and strict background >100 predicate are
unchanged. Route progress uses the existing nearest-index definition and 0.05
slack at fixture samples 16 and 32. As in the inherited contract, completion
before a checkpoint ends the trajectory; no later observation is invented. Their targets are the witness's progress,
not the original scene's hazard observations. The original scene and its gates
are never modified or acquired in this study.

Endpoint guidance is the retained Iter158 foreground visibility graph and heading
term. Route guidance is remaining route arc length from the nearest sample to
the 90% completion index, plus four times lateral Euclidean distance and 2.7
times absolute wrapped heading error toward a point 5 m ahead along the route.
Nearest ties use the first index. Scores affect ordering only. Neither guide is
an admissible cost bound, a dynamic viability certificate or background clearance.
Both retain the prior secondary score order. The shared spatial/state cells are
unchanged. Rank pruning takes the best 24 distinct cell representatives;
speed-group pruning takes representatives in rounds across rounded speed groups.

Each run has the same 18,000 attempted-transition cap, 24-node width and 96-action
horizon. All 16 runs are retained, including misses. Completion is selected only
after a full depth; hitting a budget mid-depth cannot admit a completion from
that partial depth. Early completion/empty beam stops that run. Total attempts
and background queries are reported separately; fixed expansion caps are not
equal actual work, equal wall time, or a latency benchmark. Initialization,
materialization, witness checks and independent checking are separate costs.

The checker separately reconstructs dynamics, controls, foreground geometry and
sweep, route outcomes, both progress checks, every full background mask and
completion for all witnesses and all selected paths. It mechanically replays
cell/beam selection from retained producer scores, verifies raw/source identities,
the full 16-run denominator and all trace bindings. It does not independently
recompute every unselected collision or heuristic score.

The witness audit first proves each reference command belongs to the shared
primitive alphabet. While the exact witness prefix is retained, it checks its
next child and records the first lost prefix as cell-representative replacement,
beam-width pruning or run termination. A feasible witness rejected by a hard
check, or a missing covered proposal at a completed depth, invalidates the audit.
Losing that witness does not mean all useful paths were removed. Finding another
complete path is a valid completion regardless of when the reference was lost.

Primary claim: route guidance with speed groups completes all four controls.
Independent verified completion on all four is supported; any admitted miss is
contradicted. Admission failure, missing run or resource-envelope violation is
invalid and is never silently counted as a search miss. Report each factorial
arm and each case; no significance test or population generalization. No result
establishes native recovery, information benefit, physical occupancy, safety,
continuous background clearance, road compliance or superiority to another team.
