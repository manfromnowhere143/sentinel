# Test continuation preservation before another search

12 October 2026. The four-case route/speed-group qualification claim is
contradicted. Do not promote that arm as an improved baseline or send it into
another source-scene or native recovery run on the strength of this result.
The old endpoint/speed-group arm also misses a verified opportunity. More
elaborate ranking has not removed the demonstrated coverage problem.

The next milestone is a **continuation-preservation diagnostic followed by a
fixed-budget pruning ablation**. At every registered witness's first loss, retain
the discarded state and its chosen cell representative. Under a new prospective
protocol, replay the same remaining witness commands from both states, using the
same time index, full constraints and separate scalar admission. If the witness
suffix remains admissible from both, that pair does not explain the failure.
If only the discarded state admits the suffix, the cell has demonstrably merged
states that differ in this continuation. Neither outcome proves that the surviving
state has no alternative valid continuation.

Then compare the same proposals, guide and expansion cap while changing only
state aggregation or retention. Register all variants before execution, include
an exact-state baseline and preserve failures. A smaller cell alone is not a
completeness guarantee; a width cap can still discard useful branches. A protected
reference path is allowed only as an explicitly labeled diagnostic oracle, never
as an ordinary planner input or evidence that the planner found the path itself.

Repair the reflection-control construction in a new fixture version and verify
that reflecting the complete scene twice recovers the original. Preserve the
current cases and result. Assess both fixed exposed controls and subsequently
unseen constructions before interpreting a planner improvement. The small route
score remains available for experiments, not adopted as a universal replacement.

Acceptance for a proposed baseline remains completion of every registered known
feasible control under full scalar admission, followed by one frozen original-scene
search. Resources should first be local CPU, bounded transitions and recorded total
work. Native recovery, actual trigger/history, equal-cost information ablation and
held-out transfer follow only after an admissible source-model opportunity exists.
Iter135 stays deferred; the broader monitoring and information mission is unchanged.
