tasks and improve 16/80 exposed requests versus 15/80 for shooting, with identical

proposals lead to useful future tree parents, sampled targets and complete paths.

comparison closed until all four qualify.

budgets or another planner. Each changes a second mechanism. Recommended milestone:
replace only the connector, preserve the original four cases/seeds and full
contracts, and run one prospectively frozen schedule. The retained primary OMPL
implementation supports this same directed-sampler interface; no new algorithm or
broad literature comparison is needed to select this narrow integration test.

admission rejects the execution. An admitted all-four pass supports finite planner
qualification only. Keep all failures; no outcome-dependent retry or source run.

expansion, target, checkpoint and allocation limitations before a new design.
