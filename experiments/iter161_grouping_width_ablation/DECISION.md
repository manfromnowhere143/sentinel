grouping at width 24 meets the four-control qualification bar. Removing approximate
grouping changes chicane-right from budget exhaustion to completion and reduces
total attempts across the controls. Doubling the beam width loses completions
under the fixed cap for both grouping rules. Do not equate width with a monotonic
improvement, or the first lost witness with the loss of every useful action.

This is meaningful baseline progress: a candidate now completes the disclosed
constructive controls under the complete modeled predicates. It does not show
native recovery, superiority to released planners or an information advantage.
The original exposed source scene remains unresolved, and these routes were
constructed from known commands. Keep the four-control scope attached to the result.

using this unchanged exact/24 search. Use the already retained full source-point

not a source-scene cost estimate. Use the existing full-population calibration

immediate dependency. Preserve initialization and raw-before-admission ordering.

observed source predicate and progress checkpoint; a valid partial prefix is

decision-time-history test. Reset-time success is not responsive recovery.
