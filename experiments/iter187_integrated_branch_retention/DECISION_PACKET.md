# Test the online mechanism that the retained opportunity motivates

Iter185 demonstrated one feasible continuation from a discarded prefix. Iter186
qualified a native interface that can retain such a prefix under an exact parent
identity. Neither establishes an integrated improvement. Iter187 tests the uniform
online rule with the original four cases, seeds and budgets, and reports losses.

The implementation reuses the unchanged Iter183 evaluator and primary selection,
the qualified native binary and selector, and separately implemented trajectory,
eligibility and scalar collision checkers. New code is limited to integration,
explicit event/sequence accounting, independent online selection reconstruction
and the trial record. The original dirty canonical checkout and historical
evidence are preserved; this work descends from the clean Iter186 research line.

Constructed worker qualification must precede scientific acquisition. A miss
closes this trial without a fallback. A success earns only development
qualification, followed by a new protocol for source comparison. Actual-history
recovery, measured delay and a competent responsive information comparator remain
the mission's consequential tests. See [protocol](PROTOCOL.md) and
[primary research assessment](RESEARCH.md).
