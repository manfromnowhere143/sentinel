# Test branch retention prospectively; do not select the known witness by hindsight

The original computation generated a discarded prefix with an independently
verified full-route continuation within its conditional remaining work. That
justifies a branch-retention hypothesis. It does not prove that inserting the
prefix into the original tree would reproduce the fresh conditional search, nor
that progress ranking alone improves all four cases. Two other probes remain
bounded misses, and twelve audited prefix records remain unprobed.

Next specify and qualify one deterministic alternative-branch retention mechanism.
Keep the existing selected edge; allow at most one additional already-generated,
recorded-valid, eligible prefix per connection. A candidate rule to freeze is
strict progress beyond the greatest accepted endpoint index available after the
current selection, choosing greatest index then earliest frame, evaluation and
prefix. Exclude prefixes already represented on the selected edge and exact
duplicate state/clock endpoints. Do not use final-run progress, future events,
case identity, the known successful call 83 or an outcome-selected threshold.

The retained chronology shows that this rule would act much earlier and on every
case: 39 candidate connections in total, with the first left/right candidates at
calls 1 and 2. It therefore changes later requests and allocation. Keeping the
primary selected edge does not guarantee keeping a previous success. The next
protocol must account for losses against both retained Iter178 and direct parent
Iter183, each 3/4, with the same four cases, seeds, 18,000 transitions, 120 seconds,
128-transition connections, local horizon and absolute action/checkpoint rules.

First resolve and qualify the native interface required to represent the second
branch. Preserve its exact source evaluation/prefix, parent state/clock, sequence
token and physical duration. Test duplicate/rejected/ineligible prefixes, changed
ancestry and tokens, deadline behavior, and zero-alternative compatibility with
the current bridge on constructed controls. Replay the fixed retained candidate
paths as qualification evidence; new masks must receive independent scalar replay.
Additional registration/nearest-node work must count in the original wall envelope;
already executed motion must not be refunded or counted as fresh free work.
If native planner semantics change, name that change and bind the new binary;
do not call the resulting algorithm an unchanged released planner.

Freeze this single change before one all-four integrated schedule. Retain all
negative, invalid, censored and lost-success outcomes. No seed sweep, budget
increase, new greedy replacement ranking or combined eligibility change. The
conditional witness does not open the source-comparison gate; only the original
all-four qualification can do so.

This is the next bounded test, not a commitment that retention will work. The
mission remains useful intervention from actual decision histories with measured
delay and a strong responsive comparator. Prefix geometry and offline compute
alone do not establish that mission.
