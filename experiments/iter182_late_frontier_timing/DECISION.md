# Test necessary feasibility before another preference heuristic

The audit closes its question: four verified checkpoint continuations, one
premature-completion exclusion, two progress exclusions, no unresolved or censored
probe. The retained tree contains both useful roots and states that cannot satisfy
the existing timing contract. More elapsed tree time and proximity to completion
are insufficient eligibility criteria. Preserve the adverse Iter181 result.

The next falsifiable candidate is **one necessary-constraint eligibility filter**
on late valid prefixes, before the existing selection ranking. Reject only prefixes
whose independently verified bound excludes every admissible continuation in the
declared window; a failed certificate remains eligible. Do not turn a finite search
miss into a pruning rule. Use the already observed Iter181 selection implementation
as the experimental parent, while retaining Iter178's 3/4 as the performance
comparator and Iter181's 2/4 as the direct-parent comparator. This does not promote
the failed parent to an improved baseline.

First preregister the precise integration boundary and caching identity, validate
against every applicable prefix of the retained successful paths and the four
new witnesses, and measure arithmetic cost on constructed inputs. Then freeze one
four-case integrated schedule. Keep proposals, sampling, native metric, connection
allowance, checkpoint rules and all total budgets unchanged. Bound evaluation and
cache work must consume the existing wall allowance; no free post-deadline work.
Count lost successes against both comparators and keep the all-four source gate.
No combined beam swap, increased budget or expansion-allocation change.

Why the experimental parent matters: Iter178's missed right tree reaches only
frame 15. A filter restricted to the newly audited frame-24-to-31 window would
not address that failure. Iter181 reaches this late window but admits the certified
dead ends. The proposed experiment tests whether excluding them preserves useful
opportunities; it does not assume that changing the tree will recover either case.

Three feasible left roots lacked outgoing requests, but their diagnostic witnesses
used 966–1,499 transitions and another search procedure. Allocation remains a
possible contributor, not an isolated mechanism. None of the four witnesses
completes the route; their remaining suffixes and the integrated repair remain
unobserved. Keep these limitations visible in any next candidate comparison.

No planner was changed in this audit. The mission remains actual-history useful
intervention with measured sensing/computation/actuation delay against a strong
responsive comparator. This bounded distinction between feasible and excluded
states is engineering evidence toward that mission, not its completion.
