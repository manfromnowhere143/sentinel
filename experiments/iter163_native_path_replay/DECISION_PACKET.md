# Test the admitted path in the native scene

13 October 2026. Proposed before new native outcomes.

Iter162 produced and independently checked complete 66-action paths under both
grouping rules. Exact/24 used more attempts and collision queries. Its qualification
succeeded; a search-efficiency advantage did not. The next consequential uncertainty
is whether the preselected exact/24 path survives the native scene and its numerical,
actor, rendering and termination contracts.

The recommended milestone is two fresh native replicas of that exact packet.
A collision, off-route outcome, or material model/native discrepancy falsifies the
bounded qualification. Two admitted completions with both progress checks and full
query replay support only this exposed reset-time case. Replica disagreement is
retained. Missing evidence does not become a negative scientific result.

More beam tuning would not resolve native validity. A released planner comparison
is necessary before an efficiency or competitive claim, but a faster invalid path
would not close this bottleneck. The retained [primary-source review](../iter162_source_grouping_qualification/RESEARCH_UPDATE.md)
and [decision](../iter162_source_grouping_qualification/DECISION.md) remain current
decision inputs: parallel search and constraint-query acceleration are later tests,
each subject to exact dynamics, continuous or sampled collision scope, preprocessing
cost and equal-budget comparison. No new research headline establishes superiority.

Use the existing L4 host for one start, at most 3,600 seconds and a conservative
$3 incremental compute envelope, excluding persistent storage and taxes. Recheck
provider identity, runtime and assets; qualify ownership and deadlines on Linux
before episode initialization. The [protocol](HYPOTHESIS.md) fixes the full schedule,
acceptance criteria, resource bounds and failure accounting. Local source-method
fixtures and corruptions must pass before source freeze and launch.

If native replay succeeds, test continuation from the actual nominal/monitor
history, then decision-window and equal-cost information value. If it fails, use
the retained query inputs, masks and actor telemetry to locate the discrepancy
before changing the planner. In either case, recovery at the monitor's decision
time, deployed information benefit and held-out transfer remain separate questions.
