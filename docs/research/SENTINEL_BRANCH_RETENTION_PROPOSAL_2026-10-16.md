# Preserve a useful alternative without buying more search

16 October 2026. **Status: proposed, not preregistered or executed.**
This design follows the separately admitted [Iter185 result](../../experiments/iter185_retained_prefix_admission/RESULT.md).
It specifies the next qualification work; source, binary, fixtures and a complete
execution manifest must be frozen before a new integrated acquisition.

## Question and falsifiable result

Does retaining one additional already evaluated, eligible advancing prefix per
connection repair the remaining development miss without losing a current success?
The direct parent is Iter183 and the best retained comparator is Iter178, both
3/4 on the original four cases. Only all-four completion passes the existing
qualification. Report the four individual outcomes and gains/losses against both
comparators even if the aggregate count is unchanged. A bounded miss remains
unresolved; an invalid or censored run receives no completion credit.

Iter185 establishes a specific opportunity: the discarded right-bend prefix
83/8/7 has an independently replayed full-route continuation using 1,671 additional
transitions. It does not establish that inserting that prefix into the original
tree would produce that route. A fresh conditional tree has different subsequent
parent choices and random-number consumption. Targeting that known call would
be an outcome-selected repair rather than the online rule evaluated here.

## One online rule

At connection k, retain the current selected edge exactly as Iter183 would.
Let m_k be the greatest route-nearest-point index among endpoints registered in
the tree so far, including that selected edge and any previously retained extras.
Consider only prefixes generated by this connection that pass the unchanged
physical and timing-eligibility rules, exceed m_k, are not already represented
on the selected edge, and are not exact duplicate state-and-clock endpoints.
Unknown timing eligibility remains eligible under the parent's existing rule.

Choose at most one extra prefix: greatest route index, then earliest absolute
frame, then lowest evaluation ID and prefix length. Register its entire recorded
control sequence from the exact sampled native parent. Make no new motion query
to manufacture an alternative. If the selected edge already completes, terminate
under the existing completion/deadline precedence; do not add an unnecessary branch.

This is a fixed developmental heuristic, not an optimality or completeness result.
The descriptive [original-chronology inventory](../../experiments/iter185_retained_prefix_admission/proof/online_candidate_inventory.json)
finds 39 candidate connections across all four cases (18/12/4/5), starting at
left call 1 and right call 2. It uses the original accepted tree, so it cannot
predict candidate counts after earlier extra branches change that tree. Other
recorded-label prefixes have not all received additional scalar-mask admission.

## Native interface and acceptance controls

The current [sequence-token bridge](../../experiments/iter172_integrated_rrt/bridge.cpp)
returns one endpoint, token and duration from each directed callback to released
OMPL RRT, with intermediate insertion disabled. It has no second-branch return
interface. The successor must be named as a modified RRT integration and bind its
native source, upstream revision, license, build inputs and resulting binary.
An unmodified-OMPL claim cannot survive changing its branch registration semantics.

| Qualification obligation | Required positive and rejecting evidence |
|---|---|
| Exact ancestry | Native parent identity, state and absolute frame agree; a changed parent or ambiguous identity is rejected. Numeric equality alone must not silently choose a different native parent. |
| Sequence transport | Separate tokens expand to their exact recorded controls, endpoints and physical durations; unknown/reused tokens and changed duration fail. |
| Extra-branch filtering | Invalid, ineligible, selected-edge, duplicate and nonadvancing alternatives are rejected. Exact ties follow the frozen order. |
| No-extra compatibility | With no eligible extra on constructed controls, parent choices, callback order, returned paths, stop reason and accounting match the existing bridge. |
| Resource closure | Every attempted transition remains charged, including rejected proposals. Registration and nearest-neighbor overhead count inside the original wall clock; no refunded work or restarted budget. |
| Stop semantics | Constructed expiry before/after primary and extra registration preserves timeout precedence and cannot admit a post-deadline completion. |
| Independent replay | Complete primary and extra paths, joins, all new masks, eligibility, tokens and budget arithmetic replay independently. Deliberate corruptions prove rejection. |

Qualification must exercise the actual native build and complete metadata readers,
not only isolated Python fixtures. Use the existing fifteen admitted paths as
retained numerical examples without reacquisition. Any additional qualification
queries have their own bounded manifest and scalar admission. They do not count
as new integrated outcomes. Freeze the admission scope and resource caps before
those queries; resolve native insertion semantics before registering the trial.

## Fixed integrated comparison after qualification

Use the original four cases and seeds, 18,000 attempted transitions and 120 seconds
per case, 128-transition connection allowances, eight-step local horizon and
96-action absolute horizon. Preserve initial states, dynamics, collision geometry,
checkpoints, goal bias, sampling law, metric, existing selection and timing rules.
Charge all extra bookkeeping to the same wall allowance. No seed sweep, enlarged
budget, ranking change, learned value function or eligibility change accompanies
this test. New native ancestry/registration records are necessary measurement.

Freeze one candidate and one schedule. Retain raw before independent admission.
If fewer than four complete, keep source comparison closed and use the registered
failure records to distinguish rejected motion, timing exclusions, allocation and
unresolved search misses. Do not keep tuning on the successful conditional suffix.
If all four complete, the next study compares at the unchanged actual first-fire
history; native continuation, measured sensing/computation/actuation delay and a
strong responsive comparator still require separate evidence.

## Why this is the next step

This is a targeted test of a measured loss of opportunity, rather than a claim to
have built a superior planner. Its value is a falsifiable answer under fixed cost.
The broader research standard is documented in the [dated frontier assessment](SENTINEL_FRONTIER_ASSESSMENT_2026-10-16.md).
If this mechanism fails, preserve the loss and reassess the search representation;
do not recast another local software pass as progress on useful intervention.
