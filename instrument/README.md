# Sentinel instrument evidence channel

Daniel authorized automatic progress updates on 12 October 2026. A closed result
can update the public instrument without rebuilding its historical driving scene,
its two-pose witness, or the surrounding portfolio.

`progress.json` is the explicit presentation contract. At each scientific closure,
update its iteration, source directory, concise interpretation, limits, next
question and numeric field bindings. The current-descriptor test requires the
latest RESULT to be represented; it does not infer success from its existence.
The exporter reads the exact committed tree, requires closed STATE/admission
agreement, derives numeric values from both, and binds every archive record.
No generated scientific claims or running experiments are published as results.
A new evidence format needs an explicit adapter and corruption controls.

The separate instrument workflow waits for the exact push source's full `ci`
workflow to succeed, then exports that same commit. The publisher checks CI
again, rejects iteration rollback and non-descendant science sources, and advances
`instrument-channel` with a normal fast-forward update. A pointer and its
content-addressed packet are committed together. Prior snapshots remain in the
branch. Repository access controls establish publisher authority; SHA-256 binds
bytes, not scientific correctness or independent review.

The public reader checks the pointer, packet digest, immutable source hashes,
closed state, admission and every displayed count. Active visible pages refresh
at five-minute intervals; the response cache is at most two minutes, plus upstream
GitHub delivery. Hidden pages do no periodic fetch. Failure retains the current
page's last validated packet and reports an unavailable update; a fresh page has
its deployment snapshot. There is no claim of instant delivery or durable browser
storage. The Iter42 replay and Iter155 witness retain separate source identities.
The old compatibility evidence endpoint remains explicitly a historical snapshot.

A failed or null result is publishable under the same contract. A correction or
retraction uses a later descendant source and remains explicitly labeled; it does
not overwrite old packets. Full protocol, source and scientific review remain
necessary. Automatic presentation is not automatic scientific admission.

Local checks: `python -m pytest -q tests/test_instrument_progress.py`.
Export: `python3 scripts/instrument_progress.py --output /tmp/progress.json`.
Publication adds `--publish` and requires the exact-source hosted CI observation.
No cloud experiment, GPU, safety claim or production UI release is authorized by
this file alone. Current direct operator instructions govern the requested work.
